

\# TP3 Gitea - Réponses



\## Question 1 : Quelle est la différence entre Owners et Developers ?



Les Owners administrent l'organisation et gèrent ses paramètres, ses membres et ses permissions.



Les Developers participent au développement des projets selon les droits qui leur sont accordés.



\## Question 2 : Pourquoi protéger la branche main ?



La protection de la branche main permet d'éviter les modifications directes non contrôlées.



Les développeurs doivent passer par des Pull Requests et obtenir les approbations nécessaires avant la fusion.



\## Question 3 : Pourquoi utiliser git fetch --prune ?



Cette commande récupère les informations des branches distantes et supprime les références locales des branches distantes qui ont été supprimées sur le serveur.



\## Question 4 : Quelle est la différence entre Merge Commit et Squash ?



Le Merge Commit conserve les commits individuels de la branche et ajoute un commit de fusion.



Le Squash rassemble les modifications de plusieurs commits dans un seul commit.



\## Question 5 : Comment assurer la traçabilité entre User Story et code ?



La User Story est décomposée en tâches.



Les Pull Requests sont associées aux tâches avec une référence comme Closes #NUMERO.



Les commits, les revues de code et les fusions permettent de suivre les modifications jusqu'au code final.
